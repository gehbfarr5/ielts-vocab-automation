# 日常流程与自动写入

## 用户操作

1. Goodnotes 浅色英文页面：金黄 `#E6C162` 标不会；灰蓝 `#6E83B0` 标半熟；橄榄绿 `#9EA57B` 标搭配或语境不清。保持原句完整可见，避免跨页截断。
2. 下拉控制中心，点截图快捷指令。退出控制中心并延时后截图，复制图片到剪贴板兜底，再保存至 iCloud Shortcuts 的 `/IELTSInbox/`。不另存照片，不必打开分享菜单。
3. 正常打开 Anki、同步和复习；不用给聊天发“已完成”。到期复习优先，复习后同步，让 Mac 获得最新历史。

## 后台处理

- Mac 用户会话中的 worker 每60秒扫描收件目录；等待文件稳定后按图片哈希去重。
- Apple Vision 本地OCR，再把三色标记匹配到词边界。仅当前配色、浅色页面、明确标记及高OCR置信度进入自动准入。OCR置信度和模型置信度不是实际准确率保证。
- 云端 Agent 收到标记附近的必要文本、通用词频、已知词义及相关Anki历史摘要。整张截图上传关闭。截图、文本和历史都被当作数据，分析器不获写卡工具。
- Agent 收紧误涂边界、还原词形、判断词义和固定搭配，输出 ACCEPT / DEFER / REJECT。Python复核原句精确对齐、完整句和标记；无法确定就暂缓。CEFR和学术词表尚未全面接通，缺失时明确留空；不声称有IELTS官方词频。
- 单词从Kaikki/Wiktionary按词性查询明确标注的US/UK音标，保存来源与缓存；缺项、歧义或网络失败进入等待，不让模型补猜。词组不填IPA。
- Anki写前同步并检查真实库存/历史。默认每日25个核心词且最多25张新卡；未学库存跨日占额，Context卡也占卡额度。有到期复习或额度不足则留在队列。
- 先预留额度，再按稳定EntryID写入、读回核对、记账并同步。同lemma共用Note，默认一张Recognition，必要的重要新义使用Context槽。
- 默认播放美音Samantha，英音手动点击；单词分列US/UK音标。发音使用原生TTS，不是从词典下载音频；词典提供的是音标。

## 等待与错误

自动扫描不等于即时到达：iCloud下载、分析耗时和300秒同步节流都会造成等待。Anki在Mac上需保持运行，Mac需开机、唤醒并保持用户登录；需要可用的iCloud、模型登录、联网和声音。

模型临时错误最多三次，带延迟；24小时默认最多10次分析调用。词典网络错误从5分钟退避，缺项或歧义24小时后可再查。同步失败不放新卡，后续worker重试；需要全量上传/下载、账号不符或外部字段冲突时保留错误等待人工处理，不自动覆盖。

DEFER代表需要更清晰的截图或后续审阅，不承诺其自动变为可写。重新分析会保留旧版本审计记录，但不会把旧候选当成另一条活跃队列。写入超时先查Anki实际结果，已成功的写入只补记账，不重复创建。

数据目录中的 `worker-status.json` 保存最近一轮状态/错误，SQLite保存各阶段事件及队列；配置、截图、词条、缓存、令牌均不进Git。日志轮转、持久错误主动通知和长期备份仍属下一阶段运维工作。

## Mac Server迁移

本机是当前唯一写入端。迁移时先停本机worker并关闭写入，备份/转移私有状态与IPA缓存；服务器独立登录iCloud、Anki和模型服务，核对声音、牌组、时区和现有卡片，再绑定新主机并开启写入。不能只复制代码后让两端同时运行。路径重定位工具默认只检查、不写入；迁移不复制账号凭据到公开仓库。

## 数据源取舍

复用[Kaikki结构化词典](https://kaikki.org/dictionary/English/index.html)与其上游[wiktextract](https://github.com/tatuylonen/wiktextract)的输出，适配为有超时、大小限制、词性/口音校验的单词查询；避免下载数GB全量数据、抓网页猜口音或把模型生成音标作为词典证据。音标字段保留Wiktionary和CC BY-SA 4.0署名链接。上游单词JSON接口若改变，显式等待修复；本地已核验缓存可继续使用。

## 2026-09-17 模型与历史范围更新

后台明确指定 `gpt-5.6-sol` / `medium`，沿用ChatGPT登录；不随当前聊天界面的模型选择变化。真实只分析验收已返回相同模型/强度标识；模型不可用时显式报错，不静默换型号。模型名称固定不等于权重版本永久不更新。

可选方案对比：Luna适合高吞吐、明确的提取/分类；Sol适合需要判断的模糊任务。本任务含误涂边界、多义词与搭配，暂选Sol medium，先以质量为重；不宣称已有跨模型基准证明其最优。无需最高推理档或新增API密钥。依据：[官方模型选择说明](https://learn.chatgpt.com/docs/models)。

出站历史按实际标记目标匹配：支持完整词边界、常见屈折及本地已记录的表面词形；短语需出现在附近上下文且标记到内容词。无关词义/历史不发送；卡片编号和原始逐次复习日志去除，仅保留相关词的interval/reps/lapses及快照时间。未见过的不规则词形可能漏检，缺失不代表掌握；这是检索规则，不用于推导新词或词族。

本地仍可保存全部受管历史用于去重和额度。每次调用写出私有analyzer-call.json记录请求模型/强度、CLI报告值、返回码及发送条目数，不记录凭据。回退前有私有配置快照；源码可通过Git恢复。本次只分析复用既有截图，没有重导或修改Anki卡。

语境/搭配/构词扩展已接入本机新截图流程：精简解释常显，补充内容默认折叠，详见[课程使用与迁移前交接](course-trial-handoff.md)。本轮依用户要求不运行测试，实际课程效果待确认。词典语义缓存与音标缓存相互独立；语义网络失败使用截图处理重试，缺项显式记录，不补猜构词。
