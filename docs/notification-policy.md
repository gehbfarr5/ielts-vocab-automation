# 同步提醒与弹窗清单

2026-09-17。Mac Anki 25.09.4源码和本机sync.pyc确认：aqt.sync同步NO_CHANGES完成分支调用tooltip(tr.sync_collection_complete())。AnkiConnect的sync调用最终进入mw.onSync，因此后台同步会触发Anki原生界面。后台Python及当前“雅思截屏 控制中心”没有自定义成功通知动作。

## 当前决定：保留Anki原状

用户确认提示来自Anki后撤回屏蔽要求。本地ielts_quiet_sync插件已移出Anki插件目录，项目中的插件代码已移除。同步成功、进度、错误和冲突提示全部保持Anki原生行为；Mac Server迁移无需携带屏蔽插件。没有修改Anki本体或AnkiConnect。

此前插件仅安装、未由本任务重启加载；本次不主动重启或触发同步。如用户曾自行重启使其加载，完全退出并重新打开Anki即可清除内存中的屏蔽逻辑。

## 当前流程可能出现的界面

| 类别 | 触发条件 | 处理 |
|---|---|---|
| 同步完成短暂提示 | Mac Anki正常完成同步，包括无变更 | 保留Anki原生提示 |
| 同步进度/媒体同步状态 | Anki正在同步或传输媒体 | 保留，属于进度而非成功通知 |
| AnkiWeb登录/认证错误 | 未登录、凭据失效 | 保留 |
| 网络/服务/同步异常 | 同步出现错误 | 保留；后台异常另写日志，不保证都会弹窗 |
| 上传/下载选择 | 需要全量同步或两端冲突 | 保留；不自动选择 |
| 空集合上传/下载确认 | 可能用空集合替换数据 | 保留 |
| AnkiWeb服务端消息 | 同步响应包含server_message | 保留 |
| 快捷指令系统授权/运行错误 | 初次权限、文件访问或动作失败 | 系统决定；本机同步的快捷指令没有自定义提醒动作 |

清单范围为本项目链路，不是所有Anki插件或系统的全部弹窗。当前快捷指令只有关闭控制中心、延时、截图、复制剪贴板、自动存文件五个动作；未设置显示通知、显示提醒、菜单或询问保存位置。照片另存已去除。iPad/iPhone实际副本状态未在本轮重新读取。

正常收件、分析、写卡、pending/额度等待在Python后台没有弹窗；持久故障主动推送仍未实现。成功提示和故障诊断均保持原状。

撤回状态：屏蔽插件已移除，原生提醒保留。
